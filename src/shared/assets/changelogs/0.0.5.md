---
title: Connectome 0.0.5 alpha
date: 2026/10/18
---

The first version Connectome numbers as its own. Nothing before it was a
Connectome release.

- Connectome is the native desktop control surface for RRFlow, built as a
	Tauri 2 application for Windows, macOS, and Linux, at
	`github.com/rrflow/connectome-development`.
- One contracted engine: `src-tauri/Cargo.lock` pins the exact RRFlow
	revision, and the native client, the generated TypeScript SDK, the staged
	`rrflow` sidecar, the CI matrix, and the About tab all derive from that one
	pin. A gate fails the build when any of them disagree.
- Start serving runs RRFlow's contracted sequence — install plan, sealed
	apply, serve on a loopback port the operating system chooses, authenticated
	readiness — and shows each stage as it happens. The bundled `rrflow` sidecar
	runs only when it still hashes to the digest this build was made with.
- The public RRD handshake (liveness, readiness, capabilities) runs on the
	generated `@rrflow/rrd-client` SDK; no wire shape is written by hand.
- Database, vector, graph, and rrflowKV storage lenses read live state from
	the served estate through the native RRD client.
- Versioning is contracted: `package.json` owns the version and the maturity
	channel, every other copy is derived and checked, and the version stays at
	0.0.5 alpha until the product works end to end.
- The inherited vendor's hosted-service surface is gone, not renamed: its
	cloud account, organization, billing, support and referral pages, its
	instance dashboard and monitoring views, its assistant, its newsfeed, its
	support-chat and analytics tracking (which posted a visitor cookie, the
	page, and on sign-in the account email to a tracking endpoint), and the
	native command that carried those requests.

Still inherited, and leaving in the next versions rather than being renamed:
the inherited UI kit, and the query, explorer, designer, GraphQL, functions,
migration, parameters and sandbox views, which still run on the inherited
query client rather than on RRD.
